## 2. 动力学方程组

### 2.1 方程 1：核周富集（两态陷阱模型）【重写，原式(1)废弃】

$$\frac{\partial C_f}{\partial t} = \frac{\partial}{\partial r}\Big[D_0\frac{\partial C_f}{\partial r}\Big] - k_{on}^{trap}(r)\,C_f + k_{off}^{trap}\,C_t - J_{bind}(r)$$

$$\frac{\partial C_t}{\partial t} = k_{on}^{trap}(r)\,C_f - k_{off}^{trap}\,C_t$$

其中 K_trap(r) ≡ k_on^trap(r)/k_off^trap，在核周壳层（细胞器密集区）取高值。

**来源与修正说明**：扩散-捕获（diffusion-trapping）标准两态反应-扩散形式。v1 的单一变扩散系数形式 ∇·[D₀/(1+K_trap)∇C] 在物理上不能产生富集——无通量稳态下浓度均匀（低扩散区只"分压"不"蓄水"）；正确的粗粒化方程必须包含漂移项 −∇·[D₀C/(1+K)²∇K]，稳态给出**总浓度富集比 = 1 + K_trap(r)**（详见修改建议 A1 的推导）。

**模型预言（可证伪）**：稳态荧光成像的核周/胞质总信号比 ≈ 1 + K_trap，可据此反推 K_trap。

**诚实声明**：平衡态自由浓度处处均匀，陷阱不提高核周自由浓度、也不直接加快 FG 结合速率；其增益是**动力学性**的——将物料预置到核膜附近形成可消耗的局部库，在 ~120 s 的瞬态时间尺度上提高早期入核通量。

**来源引用**：【待确认】Chae et al., iScience, 2024——需核对其"trap"为结合位点（支持本节）还是纯慢扩散区（本节立论需重写）；本节标题不再使用"Chapman"字样（与引文不符）。

### 2.2 方程 2：与 FG-Nup 结合（质量作用定律）

$$\frac{dC_{bound}}{dt} = J_{bind} - k_{off}^{FG}\,C_{bound} - J_{partition}$$

$$J_{bind} \equiv k_{on}^{FG}\cdot C_{FG\text{-}Nup}\cdot C_f(R_N,\,t)$$

其中 R_N 为核膜位置，C_f(R_N,t) 为核膜处**自由**液滴浓度（表面通量）。ODE 版可合并为伪一级：K_FG* ≡ k_on^FG·C_FG-Nup/k_off^FG。

**修正说明**：v1 中 J_bind 从未定义、C_peri 无演化方程，守恒断裂；现 J_bind 与本式源项严格相等（同一流的两面记账），消耗的是核膜处自由液滴。

**来源**：质量作用定律标准形式。C_FG-Nup 代表货物特异性作用的 FG-Nup（Nup62、Nup98 等），换货物只需替换 C_FG-Nup 与 k_on^FG/k_off^FG——模型的泛化入口。

### 2.3 方程 3：分配进入 NPC 相与形变耦合（Cahn–Hilliard + 界面演化）【修正量纲与界面分工】

总自由能泛函：

$$F = \int_V \Big[f(C) + \frac{\kappa_{CH}}{2}|\nabla C|^2\Big]\,dV + \int_{\partial\Omega} \gamma\, dA$$

化学势与守恒动力学：

$$\mu = \frac{\delta F}{\delta C} = f'(C) - \kappa_{CH}\nabla^2 C, \qquad \frac{\partial C}{\partial t} = \nabla\cdot\big[M_{CH}\,\nabla\mu\big]$$

**界面分工声明（新增，B4）**：|∇C|² 项描述 NPC/FG 相**内部**浓度过渡的弥散界面；∫_∂Ω γ dA 专指**液滴与 FG 相之间的锐利边界**（由 A(t) 跟踪）。两项描述不同几何对象，界面能量不重复计入。

**来源**：Cahn & Hilliard, J. Chem. Phys., 1958；Cahn, Acta Metall., 1961。去溶剂化能作为分配驱动力的定量依据：Frey et al., Cell, 2018（K_p 由 ln K_p^NPC = −ΔG_desolv/(k_BT) 给出，ΔG_desolv 取荧光分配实验值，**禁止代入对接打分**，见 §5 参数表注）。

### 2.4 方程 4：界面演化（Allen–Cahn 形式）【替换原式(5)形变方程】

$$v_n = -M_n\left(\frac{\delta F}{\delta n}\right)_{\!interface}$$

**修正说明（B3）**：v1 的 v_n = −L_chem[μ] + L_γ·γ·H 中两项量纲不同（γ·H 为压力量纲），不能相加。Allen–Cahn 形式以单一迁移率作用于总自由能的界面变分导数，曲率驱动（原 γ·H 项）自动包含于 δF/δn。

**耦合通道**：浓度场 C 决定 μ → 界面两侧 μ 跳变驱动界面运动；界面形变 A 改变边界条件 → 反馈 C 的空间分布。

### 2.5 方程 5：ODE 简化（充分混合极限，单一参数化）【替换原式(6)(9)及 J_partition】

$$\frac{dC_{bound}}{dt} = J_{bind} - k_{off}^{FG}\,C_{bound} - J_{partition}$$

$$J_{partition} \equiv k_{relax}(A)\cdot\big(K_p^{NPC}\,C_{bound} - C_{NPC}\big)$$

$$\frac{dC_{NPC}}{dt} = J_{partition} - J_{release}$$

$$\frac{dA}{dt} = k_{deform}\cdot\big(A_{eq}(C_{NPC}) - A\big)$$

**修正说明（A3）**：v1 同时存在弛豫式（式6）与独立转移流 J_partition = k_trans·C_bound，同一过程两套参数化。现删除 k_trans，将 **J_partition 定义为弛豫交换通量本身**：交换项在 C_bound + C_NPC 中严格抵消（守恒闭合），交换停止 ⇔ C_NPC = K_p^NPC·C_bound（分配系数作为平衡比自然出现）。

**来源**：Cahn–Hilliard 充分混合极限的简化；k_relax 正比于接触面积 A。

### 2.6 方程 6：释放进入核质（化学势梯度驱动 + 可选核质汇）

$$J_{release} = k_{release}\cdot\Big(C_{NPC} - \frac{C_{nuc}}{K_p^{nuc}}\Big)$$

$$\frac{dC_{nuc}}{dt} = J_{release} - k_{target}\cdot C_{nuc}, \qquad \frac{dC_{target}}{dt} = k_{target}\cdot C_{nuc}$$

**修正说明（A2）**：v1 的 dC_nucleus/dt = J_partition − J_release 接错了流（绕过 NPC 区室），现改为接收 J_release。

**k_target 的物理依据**：ALKBH5 为 m⁶A 去甲基化酶，入核后结合核内 m⁶A 靶 RNA——核质侧靶点汇有直接生物学基础。k_target > 0 时构成"等效棘轮"，使 η(∞) → 1（见 §6）；k_target = 0 退化为纯平衡分配。两种取值均应在文中声明。

**来源**：线性 Onsager 关系。经典核转运由 RanGTP 梯度驱动释放（Izaurralde et al., EMBO J, 1997）；ALKBH5 不依赖 importin-β（Chen et al., 2026），本模型以化学势梯度 + 核质侧汇描述，为**假说**（诚实声明）。

### 2.7 方程 7：入核效率定义【修正】

$$\eta_{nuclear}(t) = \frac{C_{nuc}(t) + C_{target}(t)}{C_{total}}, \qquad C_{total} = \int (C_f + C_t)\,dV + C_{bound} + C_{NPC} + C_{nuc} + C_{target}$$

**修正说明（A2）**：v1 的 C_total 含无演化方程的 C_peri；现 C_cyto/C_peri 是同一空间场 C_f 的两个区域（非独立区室），核周富集体现在 K_trap(r) 的空间分布中，C_total 由方程组自动守恒。

## 3. 完整方程组汇总

```text
(1a) ∂C_f/∂t   = ∂_r[D₀ ∂_r C_f] − k_on^trap(r)·C_f + k_off^trap·C_t − J_bind(r)
(1b) ∂C_t/∂t   = k_on^trap(r)·C_f − k_off^trap·C_t
(2)  dC_bound/dt = J_bind − k_off^FG·C_bound − J_partition
(3)  J_partition ≡ k_relax(A)·(K_p^NPC·C_bound − C_NPC)
(4)  dC_NPC/dt   = J_partition − J_release
(5)  dA/dt       = k_deform·(A_eq(C_NPC) − A)
(6)  J_release   = k_release·(C_NPC − C_nuc/K_p^nuc)
(7)  dC_nuc/dt   = J_release − k_target·C_nuc
(8)  dC_target/dt= k_target·C_nuc
(9)  J_bind      = k_on^FG·C_FG-Nup·C_f(R_N, t)
(10) η_nuclear   = (C_nuc + C_target)/C_total
```

## 6. 热力学平衡与效率上限【新增，B1】

本模型四步全为被动过程（扩散、质量作用、分配、线性 Onsager 释放），系统必然弛豫到热力学平衡，此时所有净通量为零。逐级平衡条件给出：

- C_t = K_trap·C_f
- C_bound = K_FG*·C_f（K_FG* ≡ k_on^FG·C_FG-Nup/k_off^FG）
- C_NPC = K_p^NPC·C_bound
- C_nuc = K_p^nuc·C_NPC

归一化 C_f = 1，**k_target = 0 时**：

$$\eta(\infty) = \frac{K_p^{NPC}\,K_p^{nuc}\,K_{FG}^*}{(1+K_{trap}) + K_{FG}^*\,\big(1 + K_p^{NPC} + K_p^{NPC}K_p^{nuc}\big)}$$

一般 **η(∞) < 1**，由分配系数完全决定。因此：

1. 实验观测的"~120 s 入核完成"重述为：**达到 η(∞) 的 95% 需 120 s**（t₉₅ = 120 s，用于标定 k_release 及各速率常数的相对大小）。
2. 若实验显示接近完全入核，两条自洽路径：(i) discussion 承认存在未建模的非平衡驱动；(ii) 启用 k_target > 0 的核质侧汇——入核物料被核内靶点（m⁶A RNA）螯合、移出移动库，等效棘轮使 η(∞) → 1。**推荐 (ii)**，物理上自洽且不改框架。

## 7. 过孔实体假设与模型交接【新增，B2 与 C1】

**尺度问题**：相分离液滴典型 ≥100 nm，NPC 中央通道 ~40–50 nm。本模型采用**变体 (i)：凝聚态润湿穿越**——液滴以形变的凝聚态润湿 FG 相并整体通过（与 §2.3 Cahn–Hilliard 模块一致；Wang et al., Mol Plant, 2023 支持该方向）。**变体 (ii)：单体穿梭**（液滴在孔侧解聚为单体/寡聚体过孔、核质侧重聚；Frey 2018 框架描述的正是单体过孔）置于 Supplement：此时 §2.3–2.5 的分配对象改为单体浓度，液滴充当缓慢单体储库。

**判别实验**：Chen et al. 2026 时间序列成像中，液滴过孔时**逐渐缩小**支持变体 (ii)，**完整通过/拉伸**支持变体 (i)。【待核对】

**与入膜篇的交接**：入膜模型输出的胞质液滴浓度（C_cyto，含内含体逃逸因子 η_escape）即本模型的初始条件 C_f(r,0)；两篇符号已统一（K_p^NPC vs K_p^lipid、κ_CH vs κ_bend）。

## 9. 在 Wiki 中的标注建议（更新版）

> "We model nuclear entry as a four-step kinetic process: (1) perinuclear accumulation via reversible trapping by the organelle-dense perinuclear network, modeled as a two-state (free/trapped) reaction–diffusion system; the steady-state enrichment ratio equals 1+K_trap, providing a directly testable prediction against fluorescence imaging. (2) Binding to FG-Nups via mass-action kinetics. (3) Coupled partitioning and deformation within a Cahn–Hilliard framework, where the concentration field describes the FG-phase interior and an explicit surface term tracks the droplet–pore boundary. (4) Release into the nucleoplasm driven by chemical potential gradients. All steps are passive; the system therefore relaxes to a thermodynamic equilibrium whose nuclear fraction is set by the partition coefficients K_p and K_p^nuc, and we define the experimentally observed ~120 s entry time as the time to reach 95% of this equilibrium efficiency. We assume the condensate wets and traverses the FG-Nup phase as a deformed liquid; a monomer-shuttling variant is discussed in the Supplement."
